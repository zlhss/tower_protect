塔防原型游戏（Tower Defense Prototype）

本项目是一个 用于快速验证玩法与架构想法的塔防类原型游戏。
项目目标并非完成度或美术表现，而是通过最小可行实现（Prototype）的方式，探索 角色控制、状态管理以及移动端适配方案。

🎮 游戏玩法

使用 W / A / S / D 控制角色移动

按 J 键 拾取并放置防御塔

敌人会不断向地图中心的宝石靠近

玩家需要在 角色血量耗尽之前，合理布置防御塔，阻止敌人接近核心目标

✨ 项目特点
1. 基于状态机的角色设计

角色行为采用 状态机（State Machine）模式实现，使角色逻辑高度解耦，便于扩展和维护。

当前状态示例：

待机（Idle）

移动（Move）

搬运防御塔（Carry）

可方便扩展：

攻击状态

受击状态

技能释放状态

该设计使新增行为无需修改原有逻辑，提升了代码可读性与扩展性。

2. 快速原型导向的开发方式

本项目强调 “想法验证优先”：

不追求完整数值和平衡

不追求美术完成度

重点验证：

操作是否顺手

玩法循环是否成立

架构是否适合后续扩展

适合作为后续正式项目的设计与技术基础。

3. 面向移动端的操作设计

游戏支持 虚拟摇杆输入，为移动端适配提前进行设计：

摇杆用于角色移动

操作逻辑与键盘输入保持一致

为后续 Android / iOS 适配预留接口

游戏类型：塔防 / 动作原型
